# Recycler depends on the reusable bot framework, built straight from the
# Framework repo. The framework pulls in every shared runtime dependency
# (discord.py, asyncpg, redis, fastapi, pillow, numpy, ...), so Recycler's
# own requirements are intentionally tiny.
#
# Pinned to a specific framework commit for reproducible builds. This also
# busts the Docker layer cache on every framework bump: the `pip install`
# layer is keyed on this file, so changing the commit forces a fresh pull
# (an unchanged `@main` would be served stale from cache). To adopt a new
# framework version, update this SHA.
bot-framework @ git+https://github.com/HiLleywyn/Framework.git@d0f95b0cc8c9292121acd7156a789af5f238cd6c
